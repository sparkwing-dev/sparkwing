NOTE: controller.secretsKey.name is empty, so this PostgreSQL controller
refuses to store secrets until it has a key. It has stored none yet, so a new

  (umask 077 && openssl rand -base64 32 > /tmp/sparkwing-key)
  kubectl -n {{ .Release.Namespace }} create secret generic sparkwing-secrets-key \
    --from-file=key=/tmp/sparkwing-key
  helm upgrade {{ .Release.Name }} sparkwing/sparkwing-full \
    --reuse-values --set controller.secretsKey.name=sparkwing-secrets-key

NOTE: controller.secretsKey.name is empty, so on its first secret write this

  (umask 077 && kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "sparkwing-full.controller.fullname" . }} -- \
    cat /data/secrets.key > sparkwing-secrets.key)
{{- if eq .Values.controller.storage.type "emptyDir" }}

  controller.storage.type is emptyDir, so the key and the state DB both go
  with the pod; supply a key before storing anything you need to keep.
{{- end }}

To manage the key as a Secret, create it from that same file, never from a
new key:

  kubectl -n {{ .Release.Namespace }} create secret generic sparkwing-secrets-key \
    --from-file=key=sparkwing-secrets.key
  helm upgrade {{ .Release.Name }} sparkwing/sparkwing-full \
    --reuse-values --set controller.secretsKey.name=sparkwing-secrets-key

To change keys later, set the old key as controller.secretsPreviousKey and the
new one as controller.secretsKey, then run `sparkwing secrets rotate`.
