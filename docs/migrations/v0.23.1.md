# v0.23.1 Migration Guide

## Runs-store schema moves to version 12

Version 12 adds repository-provenance state to persisted child triggers. The
migration is automatic and preserves existing rows, which default to explicit
repository routing.

A version 12 store cannot be opened by Sparkwing v0.23.0 or earlier. Before any
process migrates a shared local store, replace every CLI, daemon, and wrapper
binary that can open it with v0.23.1 or later. Stop the old daemon before the
first version 12 process starts, then restart it from the upgraded binary.

For an installation where processes do not share a store, upgrade each store's
readers together. No configuration or pipeline source change is required.
